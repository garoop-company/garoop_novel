# ブランド素材

`garuchan-source.png`（1254×1254）が唯一の元。
ここから下の素材をすべて作っている。作り直すときもここから。

この絵は **余白なし** 型。外側の余白を落としてから、その形で抜いている。
余白の色や角丸の半径は絵ごとに変わるので、差し替えるたびに測り直すこと。

## 書き出したもの

| ファイル | 用途 | 透過 |
|---|---|---|
| `src/app/icon.png` | 一般のアイコン（512） | あり |
| `src/app/favicon.ico` | タブ（16/32/48/64 を内包） | あり |
| `src/app/apple-icon.png` | iOS のホーム画面（180） | **なし** |
| `public/icon-maskable-512.png` | PWA の `maskable` | **なし** |

透過を分けているのには理由がある。
iOS は透過部分を黒で合成し、`maskable` は端末が四隅ごと切り抜く。
どちらも透過のままだと欠けて見えるので、その 2 つだけ背景を塗ってある。

## 注意

- `public/garuchan.*` は画面のなかで使うマスコットで、アイコンとは別物。
  ここの差し替えでは触っていない。
- 以前あった `src/app/icon.svg` は削除した。
  中身は旧マスコットを自動トレースした 700KB 超のパスの塊で、
  Next.js が icon.png より優先して配るため、差し替えても古い絵が出ていた。
